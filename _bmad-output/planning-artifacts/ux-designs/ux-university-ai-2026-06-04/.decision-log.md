# Decision Log — University AI UX
Date: 2026-06-04

## Visual Identity
- Platform: White-label institutional web app — neutral enough for any university to skin
- Color anchor: Navy #1B2A4A primary, Crimson #A63232 accent, white/light-gray surfaces (#FFFFFF / #F8F9FB), neutral text #1F2937, border #E5E7EB
- Typography: Playfair Display for headers (serif, academic authority), Inter for body (clean, readable)
- Border radius: 8–12px (softly rounded — approachable but professional)

## Layout
- Top nav bar: logo left, Persona Switcher right, chat viewport below
- Persona Switcher: shows active personas only — hidden until launched (MVP 1: Student only)

## Interaction
- Loading state: typing indicator (three animated dots in AI bubble)
- Error state: inline error bubble in chat thread (muted crimson tone, retry button)

## Voice & Tone
- Warm and direct — conversational but professional
- Like a knowledgeable advisor, not a formal system
- Example: "You've got 3 required courses left — here's what they are..." NOT "Your remaining degree requirements are as follows..."

## Key Journey
- Maya, CS junior, Sunday evening, registration opens Monday
- Opens University AI in browser, sees empty chat thread
- Prompt: "Ask me anything about your academics."
- Asks: "What courses do I still need to complete my CS degree?"
- Gets personalized response from RAG + Student Profile
- Follows up: "Is CIS 401 offered next semester?"
- Gets answer from Knowledge Base
- Closes tab — new session on next visit

## MVP 1 Scope (UX)
- Student persona only — only active surface
- Admin, Advisor, Faculty hidden until MVP 3+
- Admission status: in scope only if in Knowledge Base or Student Profile (TBD)
- No auth, no document submission, no agentic flows
