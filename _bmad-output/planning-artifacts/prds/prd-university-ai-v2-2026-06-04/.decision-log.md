## New Decisions (v2)

### DL-014 — Product identity shift: real product, not operator-only platform
- **Decision:** University AI is a real product with real user personas (Student, Admin, Advisor, Faculty) interacting through a conversational UI. The AI Lab experimentation dimension is preserved as the platform backbone (GenOS), not the primary user-facing experience.
- **Source:** Brainstorming session + user confirmation.

### DL-015 — MVP 1 scope: Student Q&A via conversational UI
- **Decision:** MVP 1 = Conversational UI (Student persona) + RAG-powered Q&A (enrollment, courses, application status) + GenOS core + Langfuse observability.
- **Source:** Brainstorming session UJ-1, UJ-2, UJ-3.

### DL-016 — Authentication: persona switcher for MVP 1, real auth deferred
- **Decision:** MVP 1 uses a persona context switcher (dropdown/selector) — no real authentication. Real auth introduced in MVP 3 when Admin/Faculty differentiated access is required.
- **Source:** User confirmation 2026-06-04.

### DL-017 — PRD scope: MVP 1 full detail + MVP 2-5 lightweight roadmap
- **Decision:** PRD is scoped to MVP 1 with full FRs. MVP 2-5 captured as a roadmap section — enough for architectural extensibility decisions, not full FR detail.
- **Source:** User confirmation 2026-06-04.

### DL-018 — Success metrics: user-value AND platform metrics
- **Decision:** PRD carries both user-value metrics (does the product deliver value to Student/Admin?) and platform metrics (is GenOS observable, reliable, extensible?). Both are equal-weight primary concerns.
- **Source:** User confirmation 2026-06-04.

### DL-019 — Personas: 4 real users + operator
- **Decision:** Student (Maya), Admin (Sandra), Advisor (Dr. Raj), Faculty (Prof. Chen) are real product users. The platform operator (AILab) is a fifth actor who maintains and extends the system.
- **Source:** Brainstorming session.

### DL-020 — Two agent modes
- **Decision:** Platform supports assistant mode (human-initiated conversation) and autonomous mode (event-triggered background agents). MVP 1 is assistant mode only. Autonomous agents introduced in MVP 3.
- **Source:** Brainstorming session.

### DL-021 — Single pane of glass UI
- **Decision:** One conversational UI surfaces all personas. Structured UI elements (buttons, status cards, document upload) alongside chat. Persona context switched via selector, not login.
- **Source:** User confirmation 2026-06-04.
